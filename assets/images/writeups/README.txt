Writeup images live in this directory. Each Markdown writeup has its own `image` and `image_alt` front-matter fields. Set `image` to the file path, for example `/assets/images/writeups/baggage-cover.png`; the shared writeup layout will render it above the article when the field is non-empty.

You can also place images inline in a writeup body using standard Markdown:

![Registry evidence](/assets/images/writeups/baggage-registry.png)

Use descriptive filenames and avoid publishing secrets, tokens, personal data, or sensitive production evidence in screenshots.
