Place your custom card images in this folder. Profile paths use /assets/random_images/filename.png.

Skills: iconsubst1.png, iconsubst2.png, ...
Achievements: achievement1.png, achievement2.png, ...
Certificates: certificate1.png, certificate2.png, ...

Each numbered entry in _data/profile.yml has an image and key field. Set key: "yes" to highlight that card green, or key: "no" for normal styling. Images are optional; missing images leave the same-sized empty image holder.
